# 分阶段开发与验收

| 阶段 | 当前交付 | 验收方式 |
| --- | --- | --- |
| 1 · 输入与视觉分析 | Lightroom 预览导出、文件夹扫描、带路径索引的联系表和项目 Skill | 选择 3–5 张跨两种光线的原片，包含两个目录下的同名照。核对清单与联系表逐张对应 |
| 2 · 逐张调色 | 场景风格说明、绝对显影目标、限幅提示、局部建议和 HTML 报告 | 查看肤色与亮度差异，核对导出的当前滑块值、每组代表照及人工复核项 |
| 3 · 确认与虚拟副本 | 预览门槛、母片核对、读回验证、同版续做 | 在 Lightroom Classic 测试目录中执行下列主机验收；Python 与 Lua 模拟测试已涵盖流程分支 |
| 4 · 局部精修 | 面部皮肤、眼睛、头发、背景按张列出建议 | 在具体 Lightroom 版本验证人物部位选择、区域覆盖和重新打开后的持久化；逐项通过后再接入自动蒙版 |
| 5 · 批量实测 | 进度、取消、中断恢复和版本记录 | 在主机上从小批扩到 50–200 张，记录耗时、失败原片和恢复结果；个人风格学习另行开发 |

## Lightroom 主机验收

1. 用当前版本插件在测试目录导出预览，记录 Lightroom 版本、原片数量和若干原片的当前显影值。确保一张已有调整。
2. 生成两组方案。先打开 `apply-plan.csv`，应收到先预览的提示。打开 `preview-plan.csv` 并取消，副本数量应不变。
3. 确认预览，检查每组恰有一张副本。对照原片查看显影效果，核对未填写的滑块继承自原片。
4. 确认批量并中途取消。用同一文件续做两次，核对每张原片只有一个本版副本，原片显影值与第 1 步一致。
5. 修改方案中的一项值并重新生成。新的批量文件应要求重新预览。重启 Lightroom，检查已完成版本的副本、滑块和续做记录。
6. 对手工局部修饰，在虚拟副本中创建蒙版并检查边界、多人选择及 100% 视图。
