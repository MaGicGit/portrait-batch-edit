# 从光线判断肤色与质感

本手册依据 Lee Varis《Skin》第二版（2010）。下文“书页 / PDF 页”分别指印刷页码和从封面起算的文件页序，例如 54 / 76。书中用布光、通道和图层演示因果关系。下面的 Lightroom 步骤是项目对这些案例的转译。

**原书章节定位**（印刷页）。第 1 章「工作流与校准」始于第 1 页，第 2 章「人像布光」始于第 41 页，第 3 章「肤色」始于第 87 页，第 4 章「明暗与对比」始于第 117 页。第 5 章「修饰」始于第 155 页，第 6 章「特殊效果」始于第 219 页，第 7 章「打印准备」始于第 283 页，第 8 章「结语」始于第 329 页。

## 先在整张照片里找依据

1. 看鼻影朝向、下巴投影的边缘、双颊亮度差和眼中已有的反光。用这些线索说明哪一侧受主光、阴影过渡有多宽。同一地点有人转身迎光、有人背光时，分别判断。书页 47–59 / PDF 页 69–81。
2. 判断偏色覆盖多大范围。有同光线下拍的灰卡时，用它建立该光线组的白平衡起点。没有灰卡时，交叉观察可信的中性物、人物受光面的皮肤和头发。额头油亮处、金属反射、染色衣料都不宜用作灰卡。证据不足时，在备注中指明疑点。书页 34–36、99–108 / PDF 页 56–58、121–130。
3. 分开判断亮度和颜色。先看在预期显示尺寸下五官能否读清，再放大比较同一个人、同一受光面上的相邻区域。两者明暗相近却有突兀色斑，先处理色差。颜色相近而有明显暗沟，则处理局部明暗。书中肤色读数来自特定照片、色彩空间和输出条件，作者也说明它们仅供参考。以画面证据及当事人的要求决定肤色。书页 99、103–115、165–169 / PDF 页 121、125–137、187–191。

## 把局部问题写到正确位置

- **面颊红斑。** 将红斑与同光下相邻、色调均匀的皮肤比较。人工选取红斑，检查选区是否误含周围皮肤或唇缘，先轻减局部色差，再检查那里是否仍偏暗。相邻毛孔可辨、斑点融入周围且原有唇色完整时停止。只影响一个人一侧脸的问题写入 `facial_skin`。书页 165–170 / PDF 页 187–192。
- **眼下暗沟和细纹。** 找到下睑边缘、暗沟及其下方同光线的颊部皮肤。优先减弱暗沟与颊部的反差，回看原始下睑褶皱。书中图 5.8 将过度平滑与恢复部分褶皱并列。眼下皮肤归 `facial_skin`。复核虹膜时另看眼中原有反光及双眼受光差异。书页 59–60、159–163 / PDF 页 81–82、181–185。
- **发际斑点。** 放大确认是皮肤上的临时斑点还是跨过皮肤的一根头发。人工修复时从同侧、同亮度且纹理相似的皮肤取样。发丝被带进填补区或毛孔开始重复就撤回，缩小范围或换取样点。将像素修复记入 `notes` 的后续行，标记“Photoshop 人工参考”，写明斑点位置、取样区域及需保留的发丝。书页 156–159 / PDF 页 178–181。
- **保留年龄与肤色差异。** 年长者的笑纹、眼尾褶皱、长期日晒后的纹理可以是肖像的一部分。先观察同一张脸上有无局部异常色，再看背景是否抢眼。书中图 5.77–5.78 的人物保留了可辨的年龄纹理，随后的人物案例则用定向加亮强调皮肤质感。多人画面逐人评估，即使同光也保留各人原有的亮度与肤色差别。书页 108–115、204–209 / PDF 页 130–137、226–231。

## 代表照怎么验收

先用整图比较人脸与背景的注意力分配，再放大看眼下过渡、发际、颈部和唇缘。若头肩与浅色背景交界处多了一圈细暗线，人物像从背景剪出来，先回退锐化，直至边缘自然。为眼睫和发丝增强细节时，可用锐化蒙版保护大面积平滑皮肤，再缩到预期观看尺寸判断。打印用锐化和软打样另按实际尺寸、纸张及设备处理。书页 284–289、297–299、310–312 / PDF 页 306–311、319–321、332–334。

写计划时，整幅画面都有依据的改动才进入 `global_settings`，从当前读数写最终绝对值。局部建议写清画面左或右、人物、区域边界、避让位置和复核依据，标记 `proposed_not_applied`。柔焦、颗粒、交叉冲洗等属于创作取向，可在用户选定相应风格后讨论代表照。商业美容案例中的合成皮纹和形体修改同样需要明确意图。书页 178–204、210–217、220–232、251–264、329–331 / PDF 页 200–226、232–239、242–254、273–286、351–353。
